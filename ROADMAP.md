# Roadmap

Last reviewed: 2026-08-31

This roadmap is directional, not a release promise. An item is complete only
when repository evidence and acceptance checks support that status.

## Status vocabulary

| Status | Meaning |
|---|---|
| **Implemented** | Executable local behavior backed by code and proportionate verification |
| **Simulated** | Deterministic educational representation; not the named provider or production system |
| **External** | A referenced service, protocol, model, repository, or optional integration not bundled here |
| **Planned** | Intended work without a completion claim |

## Current foundation

### Implemented

- A ten-token decoder-only Transformer laboratory with deterministic CPU
  training, immutable datasets, checkpoints, provenance, and inspectable
  logits, attention, residuals, MLP activity, and gradients.
- The reasoning-lab subproject with n-gram, MLP, dense Transformer,
  scratchpad, sparse MoE, SQLite FTS5 retrieval, allowlisted symbolic tools,
  effort profiles, and reproducible evaluation.
- A Windows desktop laboratory with Persian RTL presentation, 3D and 2D
  views, architecture comparison, decoding controls, and internal
  documentation.

### Simulated

- Agent harness, context engineering, orchestration topologies, approvals,
  failure injection, budgets, traces, and deterministic event replay.
- Conceptual model-ecosystem and media-generation flows.
- CPU capacity and architecture projections that are explicitly not hardware
  benchmarks.

### External

- alef.ba public material and future program integrations.
- ChatGPT, Sora, OpenArt, Codex, Claude Code, Qwen, DeepSeek, Hermes, Devin,
  MiroFish, OASIS, and other named products or projects.
- MCP, A2A, AG-UI, OpenAPI, JSON Schema, OAuth, and OpenTelemetry
  specifications.
- Any cloud model, external API, MCP server, dataset, or model weight not
  expressly included in this repository.

### Planned

- Public repository release automation, signed Windows artifacts, a hosted
  demo, and versioned release notes.
- A bilingual source graph that connects every major explanation to its
  primary source and last verification date.
- Measured accessibility evidence for keyboard operation, contrast,
  screen-reader semantics, reduced motion, and RTL/LTR behavior.
- Reproducible performance baselines for package size, cold start, memory,
  frame rate, event throughput, and offline network requests.

## Milestone 1: Open research foundation

- Publish the governance, security, contribution, citation, comparison, and
  source-register documents.
- Add issue and pull-request templates that require status and source labels.
- Add license scanning, dependency review, secret scanning, and a
  THIRD_PARTY_NOTICES process.
- Establish a stable machine-readable concept and source schema.

## Milestone 2: Learning atlas

- Connect the digit-scale laboratory to Transformer, MoE, retrieval,
  diffusion, audio, video, code, multimodal, and agent modules through one
  progressive curriculum.
- Add inspectable training stages: data curation, pretraining, supervised
  fine-tuning, preference optimization, evaluation, deployment, and
  post-deployment feedback.
- Explain user-specific information boundaries: context, saved memory,
  retrieval, adapter tuning, provider-side training, and product telemetry are
  distinct mechanisms.
- Add safe mechanistic-interpretability labs for activation intervention,
  ablation, and refusal-direction research.

## Milestone 3: Scenario and protocol workbench

- Add forecasting, monitoring, trend analysis, horizon scanning, and
  alternative-futures scenarios with base rates, uncertainty, calibration,
  backtesting, and causal-claim warnings.
- Add a MiroFish/OASIS-inspired swarm laboratory without claiming that an
  agent narrative is a verified prediction.
- Visualize MCP host/client/server boundaries, A2A task exchange, API schemas,
  authentication, consent, idempotency, retries, rate limits, and telemetry.
- Export deterministic replay bundles containing input, seed, configuration,
  ordered events, policy decisions, terminal state, citations, and checksums.

## Milestone 4: AI Architecture Decision and Experiment Lab

- Accept a problem statement plus constraints for privacy, latency, cost,
  hardware, data, risk, and required tools.
- Compare model, retrieval, fine-tuning, context, harness, agent, protocol, and
  deployment options using explicit trade-offs.
- Run failure scenarios before recommending an architecture.
- Export an evidence-linked Architecture Decision Record with alternatives,
  assumptions, tests, risks, and rollback.
- Provide optional real adapters only after separate authorization, sandboxing,
  least-privilege scopes, and observable approval gates.

## Milestone 5: International research program

- Publish reproducible experiment packs and independent replication guidance.
- Add reviewed translations while keeping equations, identifiers, provenance,
  and citations stable.
- Invite research and educational partners through transparent RFCs.
- Report comparison data without a self-awarded "best" ranking.

## Non-goals

- Reproducing confidential internals of proprietary systems.
- Displaying or claiming access to hidden chain-of-thought.
- Presenting generated scenarios as certain forecasts.
- Bundling large third-party weights or data without license and provenance.
- Shipping safety-disabled weights or operational safeguard-bypass tooling.
