چگونه وضعیت هر روش را بخوانیم؟

این سه وضعیت عمداً با هم قابل‌جایگزینی نیستند. «مدل تشریحی» یعنی رابطه‌ها روی صفحه قابل دنبال‌کردن‌اند، نه اینکه الگوریتم در backend اجرا شده باشد.

اجراشده

کد یا وزن واقعی، مسیر اجرایی و آزمون متناسب در همین snapshot موجود است.

مدل تشریحی

ورودی→سازوکار→خروجی شبیه‌سازی شده، اما checkpoint یا اجرای کامل آن روش وجود ندارد.

مطالعه‌ای

برای جای‌دادن مفهوم در نقشه و اتصال به مقاله آمده و اجرای محلی ندارد.

01

قرارداد آزمایش

ورودی، mode و policy استنتاج متغیرهای جدا هستند. در این پروژه برچسب effort هم‌زمان تعداد کاندیدا، temperature و top-k را تغییر می‌دهد؛ بنابراین مقایسهٔ آن «سه policy با checkpoint ثابت» است، نه برآورد علّی اثر صرفِ محاسبهٔ بیشتر.

02

خانوادهٔ معماری‌های دنباله

معماری تعیین می‌کند اطلاعات چگونه میان موقعیت‌های دنباله جابه‌جا شود. LoRA، RAG و FlashAttention معماری زبانی تازه نیستند و در بخش‌های دیگر قرار می‌گیرند.

اجراشده

N-gram / مدل شمارشی

احتمال توکن بعدی از شمارش رخداد ادامه‌ها پس از یک suffix کوتاه به دست می‌آید. اگر context کامل دیده نشده باشد، backoff به suffix کوتاه‌تر برمی‌گردد.

چند توکن اخیر←شمارش شرطی و backoff←توزیع توکن بعدی

مرز پروژه: baseline واقعی است، اما شبکهٔ عصبی، حافظهٔ دور یا reasoning ندارد.

Shannon 1948 — منبع علمی ↗

اجراشده

Window MLP

شناسه‌های یک پنجرهٔ ثابت embedding می‌شوند، بردارها کنار هم قرار می‌گیرند و MLP به logit واژگان می‌رسد. ترتیب فقط از جایگاه ثابت هر ورودی فهمیده می‌شود.

هشت توکن آخر←Embedding و MLP←logit واژگان

مرز پروژه: checkpoint واقعی دارد؛ هر چیزی بیرون پنجره مستقیماً غیرقابل‌مشاهده است.

Bengio et al. 2003 ↗

مدل تشریحی

RNN / LSTM / GRU

RNN یک state را از گام قبلی عبور می‌دهد. LSTM و GRU با gateها جریان نوشتن، فراموش‌کردن و خواندن state را کنترل می‌کنند تا وابستگی‌های دور بهتر حفظ شوند.

توکن + state قبلی←gate و recurrence←state تازه

مرز پروژه: هیچ لایه یا checkpoint بازگشتی وجود ندارد.

Hochreiter & Schmidhuber 1997 ↗

مدل تشریحی

CNN / TCN دنباله‌ای

کانولوشن علّی روی همسایگی توکن حرکت می‌کند. stacking و dilation میدان دید را بزرگ می‌کنند، در حالی که محاسبهٔ موقعیت‌ها هنگام آموزش موازی می‌ماند.

نوار توکن‌ها←فیلتر علّی و dilation←ویژگی زمینه‌ای

مرز پروژه: رشد میدان دید فقط در دیاگرام است و مدل convolutional آموزش ندیده است.

ConvS2S, ICML 2017 ↗

مدل تشریحی

Encoder–Decoder

encoder کل دنبالهٔ مبدأ را بازنمایی می‌کند؛ decoder با شرط‌گذاری بر آن بازنمایی، دنبالهٔ مقصد را می‌سازد. cross-attention شکل رایج اتصال دو نیمه است.

دنبالهٔ مبدأ←encode و cross-attend←دنبالهٔ مقصد

مرز پروژه: مدل‌های عصبی محلی decoder-only هستند؛ افزودن متن RAG به prefix معادل encoder جدا نیست.

Seq2Seq, NeurIPS 2014 ↗

اجراشده

Dense Transformer

query هر موقعیت با keyهای مجاز مقایسه می‌شود، softmax وزن اتصال را می‌سازد و ترکیب valueها بازنمایی تازه را شکل می‌دهد. mask علّی از دیدن آینده جلوگیری می‌کند.

توکن‌های context←QKᵀ → softmax → V←بازنمایی و logit

مرز پروژه: Transformer دو‌لایه و میکرو واقعی است؛ foundation model عمومی نیست.

Attention Is All You Need ↗

مدل تشریحی

Long / Sparse Attention

هر توکن فقط یک پنجرهٔ محلی و چند موقعیت global را می‌بیند. الگوی اتصال، هزینه را از همه‌به‌همه کمتر می‌کند ولی باید مسیر انتقال اطلاعات مهم را حفظ کند.

دنبالهٔ بلند←پنجرهٔ محلی + global←context بلند

مرز پروژه: context کوتاه و attention متراکم است.

Longformer 2020 ↗

مدل تشریحی

State-Space Model / Mamba

SSM دنباله را با انتقال یک state فشرده پردازش می‌کند. Mamba پارامترهای انتقال را وابسته به ورودی می‌کند تا انتشار یا فراموش‌کردن اطلاعات انتخابی شود.

توکن + state←selective transition←state و خروجی تازه

مرز پروژه: selective scan یا kernel مربوط به Mamba وجود ندارد.

Mamba 2023 ↗

اجراشده

Sparse Mixture-of-Experts

router برای هر توکن امتیاز expertها را می‌سازد و فقط top-k را فعال می‌کند. در نتیجه تعداد پارامتر کل می‌تواند از پارامتر فعال هر token بیشتر باشد.

بازنمایی توکن←router → top-1 expert←خروجی expert

مرز پروژه: چهار expert و top-1 واقعی‌اند؛ برچسب معنایی یا «ذهن مستقل» برای expertها اثبات نشده است.

Switch Transformer 2022 ↗

03

آموزش، انطباق و فشرده‌سازی

این روش‌ها تعیین می‌کنند کدام پارامتر با چه سیگنالی تغییر کند. آن‌ها را نباید با معماری forward pass یا روش decoding یکی دانست.

اجراشده

Supervised Training + Scratchpad

teacher forcing در هر موقعیت payload هدف، توکن درست قبلی را در اختیار مدل می‌گذارد و cross-entropy پیش‌بینی بعدی را آموزش می‌دهد. trace تولیدی یک قرارداد خروجی است.

نمونهٔ برچسب‌خورده←masked loss + AdamW←checkpoint

مرز پروژه: وزن‌ها از initialization تصادفی آموزش یافته‌اند؛ در آموزش scratch کل payload هدف supervised است، ولی inference قاب نحوی را میزبان می‌سازد و فقط slotهای رقمی نمونه‌گیری می‌شوند.

Scratchpads 2021 ↗

مطالعه‌ای

پیش‌آموزش خودنظارتی

برچسب از خود داده ساخته می‌شود: پیش‌بینی توکن بعدی، بازسازی token ماسک‌شده یا هدف‌های مشابه. مدل پایه سپس برای دستور یا دامنهٔ خاص سازگار می‌شود.

پیکرهٔ بزرگ←هدف زبانی خودنظارتی←مدل پایه

مرز پروژه: curriculum کوچک قاعده‌محور است و pretraining عمومی ندارد.

BERT, NAACL 2019 ↗

مطالعه‌ای

RLHF

پس از SFT، انسان‌ها خروجی‌ها را رتبه‌بندی می‌کنند؛ reward model این ترجیح را تقریب می‌زند و policy با RL به سمت پاداش بیشتر حرکت می‌کند، معمولاً همراه محدودیت فاصله از مدل مرجع.

رتبه‌بندی انسانی←reward model + RL←policy تنظیم‌شده

مرز پروژه: دادهٔ preference، reward model و PPO وجود ندارند.

InstructGPT, NeurIPS 2022 ↗

مدل تشریحی

Direct Preference Optimization

DPO یک زوج chosen/rejected را مستقیماً به objective ترجیح تبدیل می‌کند. policy نسبت به reference باید احتمال نسبی پاسخ انتخاب‌شده را بالاتر ببرد، بدون reward model جداگانه.

chosen / rejected←loss ترجیح←policy تازه

مرز پروژه: فقط جهت loss مدل شده و آموزش DPO انجام نشده است.

DPO, NeurIPS 2023 ↗

مدل تشریحی

LoRA / QLoRA

LoRA backbone را ثابت نگه می‌دارد و تغییر وزن را با حاصل‌ضرب دو ماتریس کم‌رتبه یاد می‌گیرد. QLoRA backbone منجمد را 4-bit نگه می‌دارد و gradient را به adapterها می‌رساند.

مدل پایه + داده←W ثابت + BA←adapter کوچک

مرز پروژه: مدل پایهٔ pretrained یا adapter ندارد و از صفر full-parameter آموزش دیده است.

LoRA ↗ · QLoRA ↗

مدل تشریحی

Knowledge Distillation

student علاوه بر برچسب سخت، توزیع نرم teacher را می‌بیند. این توزیع شباهت و عدم‌قطعیت میان گزینه‌ها را منتقل می‌کند، اما تضمین نمی‌کند همهٔ رفتار teacher حفظ شود.

teacher + داده←soft-target loss←student کوچک

مرز پروژه: teacher/student pair آموزش داده نشده است.

Hinton et al. 2015 ↗

مدل تشریحی

Quantization

بازهٔ وزن یا activation با scale به مجموعهٔ محدود اعداد نگاشت می‌شود. post-training quantization پس از آموزش انجام می‌شود؛ quantization-aware training خطا را حین آموزش مدل می‌کند.

وزن شناور←scale + rounding←وزن کم‌بیت

مرز پروژه: checkpointها quantized نیستند و نمایش کارت فقط خطای تقریب را نشان می‌دهد.

GPTQ 2022 ↗

04

استنتاج، decoding و reasoning-time control

decoding از یک توزیع توکن خروجی می‌سازد؛ search چند خروجی را می‌سنجد؛ بهینه‌سازی kernel فقط اجرای همان محاسبه را سریع‌تر می‌کند. این سه سطح توانایی یکسان نیستند.

اجراشده

Greedy / Temperature / Top-k

temperature شکل توزیع را تیز یا تخت می‌کند؛ top-k فقط k گزینهٔ بالاتر را نگه می‌دارد؛ greedy بیشینه را می‌گیرد و sampling مطابق احتمال انتخاب می‌کند.

logitها←temperature و top-k←توکن منتخب

مرز پروژه: این مسیر واقعی است؛ nucleus/top-p پیاده نشده است.

Nucleus Sampling 2020 ↗

مدل تشریحی

Beam / Contrastive Search

beam چند فرضیهٔ فعال را گسترش و prune می‌کند. contrastive search احتمال مدل را با جریمهٔ شباهت بازنمایی ترکیب می‌کند تا degeneration و تکرار کاهش یابد.

چند پیشوند←گسترش، امتیاز، pruning←دنبالهٔ منتخب

مرز پروژه: چند sample مستقل beam یا contrastive search نیست.

Contrastive Search, NeurIPS 2022 ↗

تقریب اجراشده

Self-Consistency میکرو

ایدهٔ اصلی چند مسیر استدلال و تجمیع پاسخ‌های نهایی است. مسیرهای متنوع می‌توانند خطای یک مسیر را خنثی کنند، ولی هزینه چندبرابر می‌شود و رأی همیشه درست نیست.

یک مسئله←چند sample + aggregate←پاسخ منتخب

مرز پروژه: ۱/۴/۸ کاندیدا واقعی‌اند، اما protocol validity و verifier score نیز رتبه‌بندی را عوض می‌کنند؛ پس self-consistency خالص نیست.

Self-Consistency, ICLR 2023 ↗

مدل تشریحی

Speculative Decoding

مدل draft چند توکن ارزان پیشنهاد می‌کند؛ مدل target آن‌ها را در یک محاسبه بررسی می‌کند و الگوریتم پذیرش توزیع target را حفظ می‌کند. هدف سرعت است، نه reasoning بیشتر.

draft model←پیشنهاد + تأیید target←توکن پذیرفته

مرز پروژه: زوج draft/target و acceptance sampling وجود ندارند.

Speculative Decoding, ICML 2023 ↗

مدل تشریحی

KV Cache / MQA / GQA

در تولید autoregressive، key و value گذشته تغییر نمی‌کنند و می‌توان آن‌ها را cache کرد. MQA/GQA headهای K/V را میان چند query head مشترک می‌کنند تا cache کوچک‌تر شود.

K/V گذشته + Q تازه←reuse و grouped heads←attention گام تازه

مرز پروژه: decoder در هر گام forward کامل می‌زند و KV cache اختصاصی ندارد.

GQA, EMNLP 2023 ↗

مطالعه‌ای

FlashAttention

با tile‌بندی و محاسبهٔ online softmax، خواندن و نوشتن میان HBM و SRAM کاهش می‌یابد. نتیجه attention دقیق است؛ روش صرفاً ترتیب محاسبه را IO-aware می‌کند.

Q، K، V←tiled exact attention←همان نتیجه با IO کمتر

مرز پروژه: CPU micro است و kernel FlashAttention ندارد؛ این روش reasoning جدید نیست.

FlashAttention, NeurIPS 2022 ↗

اجراشده

Grammar Constraint + Verifier

constraint گزینه‌های نحوی نامعتبر را mask می‌کند. verifier پس از تولید، ساختار و نتیجهٔ قابل‌محاسبه را مستقل می‌سنجد و ممکن است در انتخاب کاندیدا اثر بگذارد.

logit + state قواعد←mask، decode، verify←خروجی معتبر/ردشده

مرز پروژه: validator میزبان واقعی است؛ اعتبار قالب با درستی پاسخ و با توان model-only یکی نیست.

PICARD, EMNLP 2021 ↗

مدل تشریحی

Tree of Thoughts / Planning Search

به‌جای ادامهٔ خطی، چند thought-state گسترش می‌یابد؛ evaluator شاخه‌ها را امتیاز می‌دهد و search می‌تواند lookahead یا backtrack کند.

state مسئله←expand، score، backtrack←مسیر حل

مرز پروژه: sampleهای مستقل tree search، reflection یا MCTS نیستند.

Tree of Thoughts, NeurIPS 2023 ↗

05

دانش بیرونی و حافظه

دادهٔ retrieved وارد context می‌شود، اما خودبه‌خود به وزن مدل تبدیل نمی‌شود. کیفیت پاسخ به retrieval، منبع، تازگی و grounding جداگانه وابسته است.

اجراشده

Lexical RAG / SQLite FTS5

index معکوس عبارت‌های هم‌واژه را رتبه‌بندی می‌کند، سندهای برتر با شناسه و score ثبت می‌شوند و متن آن‌ها پیش از تولید به prompt اضافه می‌شود.

query + corpus←FTS5 retrieve و inject←context بیرونی

مرز پروژه: fixture بسته ابتدا facts همان درخواست را به سند world تبدیل و در همان world بازیابی می‌کند؛ این کشف دانش ناشناخته از corpus مستقل نیست.

RAG, NeurIPS 2020 ↗

مدل تشریحی

Dense Vector Retrieval

دو encoder، query و passage را در فضای برداری می‌گذارند؛ inner product یا معیار شباهت، نزدیک‌ترین سندها را پیدا می‌کند. index تقریبی جست‌وجو را مقیاس‌پذیر می‌کند.

query و passage←dual encoder + ANN←top-k passage

مرز پروژه: embedding model و vector index وجود ندارند.

DPR, EMNLP 2020 ↗

مدل تشریحی

Hybrid Retrieval + Reranker

sparse و dense retrieval recall متفاوتی می‌دهند؛ fusion دو فهرست را یکی می‌کند و cross-encoder زوج query-document را برای precision بیشتر دوباره امتیاز می‌دهد.

کاندیداهای sparse+dense←fusion و rerank←شواهد مرتب

مرز پروژه: RAG فقط یک مرحله FTS5 دارد.

Passage Re-ranking with BERT ↗

مطالعه‌ای

RETRO / حافظهٔ بلند

پیشوند جاری برای یافتن chunkهای مشابه استفاده می‌شود و مدل با cross-attention یا recurrence روی آن حافظه شرطی می‌شود. منبع هر خاطره باید قابل‌ردیابی بماند.

پیشوند + حافظه←retrieve و cross-attend←پیش‌بینی شرطی

مرز پروژه: corpus facts کوچک است و policy حافظهٔ مکالمه یا RETRO ندارد.

RETRO, ICML 2022 ↗ · Transformer-XL ↗

06

ابزار، عامل و چندوجهی

اینجا model capability از host capability جدا می‌شود. اجرای API یا حفظ حافظه را میزبان انجام می‌دهد؛ مدل فقط می‌تواند action را پیشنهاد کند، آن هم اگر واقعاً برای این قرارداد آموزش یا prompt شده باشد.

اجراشده

Tool Use اسکریپتی

controller قطعی AST را می‌خواند، نام ابزار allowlist و آرگومان را validate می‌کند، LOOKUP/CALC را در میزبان اجرا و observation را ثبت می‌کند.

AST←validate و execute←نتیجهٔ خارجی

مرز پروژه: مدل call را انتخاب یا تولید نمی‌کند؛ دقت مسیر tools توان model-only نیست.

Toolformer, NeurIPS 2023 ↗

مدل تشریحی

ReAct / Learned Tool Use

مدل action و argument می‌سازد؛ میزبان آن را اعتبارسنجی و اجرا می‌کند؛ observation دوباره وارد context می‌شود. loop تا پاسخ یا سقف کنترل‌شده ادامه می‌یابد.

هدف + مشاهده←reason، act، observe←پاسخ/action بعدی

مرز پروژه: executor دارد، اما policy انتخاب ابزار و حلقهٔ model→tool→model ندارد.

ReAct, ICLR 2023 ↗

مطالعه‌ای

مدل چندوجهی

encoder modalityهایی مانند تصویر یا صوت را به token/embedding تبدیل می‌کند. alignment یا fusion این نمایش‌ها را با زبان متصل و decoder پاسخ را تولید می‌کند.

متن + تصویر/صوت←encode، align، fuse←پاسخ چندوجهی

مرز پروژه: API و tokenizer فقط متن DSL و رقم دارند.

CLIP, ICML 2021 ↗

مطالعه‌ای

عامل چندگامه و حافظهٔ پایدار

ارکستریتور goal را به step تبدیل، state و provenance را ذخیره، ابزار/مدل را فراخوانی و بر اساس observation برنامه را بازنگری می‌کند. permission boundary جزء الگوریتم سامانه است.

goal + state + permission←plan، execute، revise←state تازه/پایان

08

قرارداد تله‌متری

Token probability

می‌گوید مدل در یک گام چه توکنی را چقدر ترجیح داد؛ علت نهایی آن ترجیح را ثابت نمی‌کند.

Attention

وزن اتصال محاسباتی میان موقعیت‌هاست؛ به‌تنهایی توضیح علّی یا اهمیت انسانی نیست.

MoE routing

expert فعال و احتمال gate را ثبت می‌کند؛ تخصص معنایی نیازمند probe و ablation مستقل است.

Retrieval/tool log

provenance کمک بیرونی را نشان می‌دهد و باید از توان وزن‌های مدل جدا گزارش شود.
