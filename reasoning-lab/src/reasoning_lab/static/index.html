      هر «پارامتر» دقیقاً کجای سامانه اثر می‌گذارد؟

      Prompt، مدل، decoding، RAG و ابزار یک سطح نیستند. کارت‌ها را باز کنید تا سازوکار، مرز و منبع هرکدام را ببینید.

      محاسبه‌شده در همین صفحه کنترل میزبان/درخواست وابسته به مدل یا API مشاهده‌گر؛ نه کنترل

      ماتریس رابطه‌ها؛ چرا پیچاندن هم‌زمان همهٔ knobها بدفهمی می‌سازد؟
