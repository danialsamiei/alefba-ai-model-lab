# Alefba AI Model Lab 0.5.0

Release date: **2026-08-31**  
Artifact: **Windows x64 portable EXE**  
Code signing: **NotSigned**

Version 0.5.0 turns the existing micro-model and 3D architecture atlas into a
source-backed research observatory and an operational, bounded alef.ba
architecture-decision specimen.

## Implemented

- Eight-station Persian Research Observatory covering the alef.ba program,
  learning lifecycle, user-data location, system anatomy, decision applications,
  MCP/API boundaries, safe synthetic Abliteration, Decision Lab, comparison,
  and typed source classes.
- Deterministic local engines for learning-stage inspection, forecast/monitor/
  trend/foresight exercises, side-effect-free protocol flow, synthetic vector
  projection, and `alefba-apir-v1` compilation.
- Explicit `I / R / U / O` receipts. Local structural evidence can support I/R;
  U/O remain `UNKNOWN` without correctly scoped external witnesses.
- Source-backed profiles for model, product, platform, harness, protocol, and
  research-program categories, including GPT-5.6 Sol, ChatGPT, Sora, OpenArt,
  Qwen3, DeepSeek-R1, Codex CLI, Claude Code, Devin, Hermes Agent, MiroFish,
  and ComfyUI.
- English and Persian repository front pages, architecture/claim/replay/threat
  contracts, comparison matrix, typed source registry, governance, security,
  contribution, and citation metadata.
- Machine-readable synthetic-data provenance, checksum manifests, and a
  dedicated Reasoning Lab Data Card.
- Dedicated application mark, Windows icon, asset provenance, and packaged MIT/
  OFL license texts.
- GitHub CI for both Python labs, desktop tests/build, Windows packaging, pinned
  actions, CodeQL, and Dependabot configuration.

## Simulated

- Named proprietary products and production model internals are not executed.
- 3D flows, multimodal pipelines, agent topologies, scenarios, and the
  Abliteration view are educational projections with visible status labels.
- Forecast and foresight examples are deterministic exercises, not calibrated
  claims about the future.

## External / opt-in only

- Live model-provider inference, MCP/API/A2A calls, external tools, authority,
  and outcome witnesses are not bundled with the EXE.
- HTTPS source buttons open the system browser only after user action.

## Planned, not claimed in 0.5.0

- Signed release artifacts and signed semantic receipts.
- Portable replay bundles and measured accessibility conformance.
- Target-specific alef.ba renderers and separately governed live adapters.

Because the file is unsigned, Windows SmartScreen may warn. Verify the SHA-256
against the adjacent checksum before running it. A checksum establishes file
integrity relative to the published value; it does not establish publisher
identity.

## Claim boundary

The release is an educational laboratory. It does not contain proprietary
weights, private training data, hidden chain-of-thought, a production MCP
authority, a safety-disabled checkpoint, or a real-world prediction engine.
